衛星データ3D解析アプリ "Satellite 3D Playground" 仕様書
1. プロジェクト概要
目的: 3D地球儀上で、直感的な操作で衛星データを検索・表示し、クライアントサイドでのリアルタイムなバンド演算（NDVI）を体験する。

ターゲット: 開発者（技術検証・学習用）。

主要機能: マップ範囲検索、Sentinel-2画像表示、3D地形、NDVIシェーダー解析。

2. システム構成 (Architecture)
2.1 データフロー
Frontend (React): ユーザーが地図を移動し、「この範囲で検索」を実行。

Backend (Flask): 範囲(BBox)を受け取り、STAC API (Earth Search) に問い合わせ。

Backend (Flask): 検索結果から必要なメタデータ（撮影日、サムネイル、Band4(赤)とBand8(近赤外)のURL）を抽出してFrontendに返す。

Frontend (React): 取得したURLを元に、Cesiumが画像をロード。シェーダーで画素ごとに演算して色付けを行う。

2.2 技術スタック詳細
Frontend:

Build: Vite

Framework: React + TypeScript

Map Lib: Resium (CesiumJS)

Styling: Tailwind CSS (推奨: オーバーレイUIが作りやすいため)

Network: Axios (Flaskとの通信用)

Backend:

Framework: Flask

Library: pystac-client (STAC検索用)

CORS: flask-cors (Reactからのアクセス許可)

Data Source:

API: Earth Search (AWS Open Data上のSentinel-2 STACカタログ)

Assets: Sentinel-2 L2A (Cloud Optimized GeoTIFF - COG)

3. 機能要件 (MVP)
A. 3Dビューア機能 (Frontend - Resium)
基本表示:

全画面で3D地球儀を表示。

Cesium World Terrainを有効化し、山岳地帯などで地形の起伏を表示する。

カメラ操作:

マウスドラッグ、ホイールズーム、右ドラッグでチルト（傾き）操作。

カメライベント:

カメラの移動終了時に、現在の表示範囲（West, South, East, North）の座標を内部的に保持する。

B. 検索機能 (Backend - Flask)
APIエンドポイント: /api/search (POST)

入力パラメータ:

bbox: [西経, 南緯, 東経, 北緯]

date_start: 文字列 (例: "2024-01-01")

date_end: 文字列

cloud_cover: 数値 (例: 20 = 雲量20%以下)

処理:

Earth Search STAC APIに対して検索を実行。

Sentinel-2 L2A コレクションを指定。

出力レスポンス:

シーンのリスト（JSON）。各アイテムには以下を含む：

scene_id: 一意のID

date: 撮影日時

thumbnail_url: プレビュー用画像URL

assets: { red: "Band4のURL", nir: "Band8のURL", tci: "True Color画像のURL" }

C. 可視化・解析機能 (Frontend - Shader)
検索結果リスト:

検索結果をサイドバー等にリスト表示し、クリックで選択可能にする。

レイヤー表示モード: UIで以下の2つを切り替える。

True Color Mode: assets.tci (True Color Image) をそのまま地図に貼り付ける。

NDVI Analysis Mode:

Cesiumの Material (Fabric) を使用。

Uniformsとして assets.red と assets.nir の2つの画像を渡す。

GLSLシェーダー:

OpenGL Shading Language
float red = texture2D(redTexture, materialInput.st).r;
float nir = texture2D(nirTexture, materialInput.st).r;
float ndvi = (nir - red) / (nir + red);
// ndviの値(-1.0 ~ 1.0)に応じて色をリターンする処理
スライダー操作 (Optional for MVP):

「NDVIが 0.3 以上の場所だけ表示」のような閾値スライダーをUIに設置し、シェーダーのUniform変数にリアルタイム反映させる。

5. 開発ステップ (Next Actions)
この仕様書を元に、以下の順序で実装するのが最も効率的です。

Phase 1: 環境構築 & Hello World

Vite React + Resium で地球を表示する。

Flask を立ち上げ、単純なJSONを返すAPIを作る。

Phase 2: 検索機能の実装

Flaskで pystac-client を使い、固定の座標でSentinel-2を検索できるようにする。

Reactから座標を送って、結果のJSONを受け取れるようにする。

Phase 3: 画像表示とNDVI

取得したURLをCesiumに渡して画像を表示する。

NDVI用のカスタムマテリアル（シェーダー）を実装する。
